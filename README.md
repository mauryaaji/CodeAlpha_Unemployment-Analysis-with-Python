# Unemployment Analysis in India

This project analyzes unemployment trends in India using Python and Exploratory Data Analysis (EDA). It explores state-wise unemployment rates and the impact of Covid-19 through data visualization.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Insights

- Covid-19 increased unemployment significantly.
- Unemployment rates vary across states.
- Urban unemployment was higher during the pandemic.

## Conclusion

The project highlights important unemployment patterns in India using data analysis and visualization.
